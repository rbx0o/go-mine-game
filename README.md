# ⛏️ go-mine-game

Учебная HTTP-игра на Go об управлении угольной шахтой. Игрок нанимает шахтёров, накапливает уголь и покупает оборудование. Цель — приобрести всё оборудование за минимальное время.

Проект создан для практики goroutines, channels, `context`, mutex, интерфейсов, обработки ошибок и REST API. Это учебная, а не production-ready реализация.

## Возможности

- пассивный доход предприятия;
- три класса шахтёров, каждый работает в отдельной goroutine;
- найм шахтёров и покупка оборудования за уголь;
- промежуточная статистика и итоговый результат;
- ручное и автоматическое завершение игры;
- отдельные жизненные циклы игры и HTTP-сервера;
- graceful shutdown HTTP-сервера.

## Запуск

Требуется Go 1.25+.

Создайте `.env` по образцу `.env.example`:

```env
HTTP_HOSTNAME=localhost
HTTP_PORT=8080
```

Затем запустите:

```bash
go mod download
go run .
```

Для ручной проверки API в каталоге [`bruno`](./bruno) лежит готовая коллекция запросов.

## API

| Метод | Endpoint | Назначение |
|---|---|---|
| `POST` | `/game/start` | Запустить игру |
| `POST` | `/game/stop` | Завершить игру вручную |
| `GET` | `/game/state` | Получить состояние игры |
| `GET` | `/game/result` | Получить итоговый результат |
| `GET` | `/enterprise/info` | Получить текущее состояние предприятия |
| `POST` | `/miners` | Нанять шахтёра |
| `GET` | `/miners/info` | Получить характеристики классов |
| `GET` | `/miners/all` | Получить всех шахтёров |
| `GET` | `/miners/active` | Получить активных шахтёров |
| `GET` | `/miners/inactive` | Получить завершивших работу шахтёров |
| `POST` | `/equipment` | Купить оборудование |
| `GET` | `/equipment` | Получить статус покупки оборудования |
| `GET` | `/equipment/info` | Получить стоимость оборудования |
| `POST` | `/server/stop` | Корректно завершить приложение |

`/miners/active` и `/miners/inactive` поддерживают фильтр `?type=small_miner`. Доступные типы: `small_miner`, `normal_miner`, `strong_miner`.

Пример найма шахтёра:

```json
{
  "type": "small_miner"
}
```

Для покупки оборудования используются типы `pickaxe`, `ventilation` и `trolleys`.

## Структура

```text
domain/    — доменные сущности и правила
service/   — сценарии игры и фоновые процессы
transfer/  — HTTP-сервер, обработчики и DTO
bruno/     — коллекция HTTP-запросов
main.go    — сборка и жизненный цикл приложения
task.md    — исходное учебное задание
```
